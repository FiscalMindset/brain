# SecondBrain — Vision

SecondBrain turns scattered information into completed work: INFORMATION → UNDERSTANDING → KNOWLEDGE → IDEAS → PROJECTS → EXECUTION. Every AI conclusion is traceable to a source; every external action needs human approval. Switch rooms (see `../architecture/SWITCH_ARCHITECTURE.md`) are where people and agents collaborate; the web UI is the personal command center.

## Goals
1. Unified ingestion with provenance. 2. Cited research. 3. Knowledge graph. 4. Project execution. 5. User-controlled memory.
